# gaSampling
Multistage stratified cluster sampling package.

The test scripts to run are:
subset_tests.R - Do not run the multiple runs unless desired (may take long so maybe run 3 seeds if needed)
joint_vs_alt_test.R

To run the test files follow these steps:
1) Ensure that the required dataset is in the same directory.
2) Rather step through the files line by line to see whats happening at each test.
